Every concept explanation must open with an explicit "what issue are we solving right now" statement plus a "how we're going to do that" high-level bullet list — *before* any pseudocode.

**Why:** captured 2026-07-20 during Phase 4 (top-level comments). User wants the framing up front so they can evaluate the approach before seeing implementation shape, rather than inferring intent from pseudocode alone. See [[project-phase-status]].

**How to apply:** for every "next"/"what's next" reply in this project, structure as: (1) short "what we're solving" statement, (2) bullet list of "how", (3) then pseudocode/decisions. Applies to all future phases, not just Phase 4.
